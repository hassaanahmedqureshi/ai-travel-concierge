# AI Travel Concierge ✈️

A conversational trip planner powered by the Gemini API. Describe your trip, get a personalized day-by-day itinerary, and refine it through conversation.

## Tech Stack

- [Next.js](https://nextjs.org) — React framework
- [Gemini API](https://ai.google.dev) — Conversational AI
- [Tailwind CSS](https://tailwindcss.com) — Styling
- [Vercel](https://vercel.com) — Deployment
